# Changelog

All notable changes to NeuraCode will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-10-06

### Added

#### Core Features
- **Code Brain**: Deep codebase understanding with code graph
  - AST parsing with tree-sitter
  - Semantic search
  - Impact analysis
  - Architecture detection
  - Hotspot identification

- **Predict Engine**: Anticipatory context preparation
  - Task classification
  - Context prediction
  - Smart pre-fetching

- **Learn Engine**: Continuous learning
  - Code style detection
  - Pattern recognition
  - Knowledge accumulation
  - Cross-session memory

- **Multi-Modal**: Visual content understanding
  - Architecture diagram parsing
  - Flowchart recognition
  - Whiteboard photo understanding
  - OCR text extraction

- **Collaborative Reasoning**: Multi-agent collaboration
  - Task decomposition
  - Parallel execution
  - Knowledge fusion
  - Conflict resolution

- **Multi-Agent Support**: Universal agent integration
  - Claude Code
  - Cursor
  - Codex
  - Gemini CLI
  - OpenCode
  - GitHub Copilot
  - Windsurf
  - Cline
  - Aider
  - Continue

#### CLI Commands
- `neuracode init` - Initialize project
- `neuracode index` - Index codebase
- `neuracode search` - Semantic search
- `neuracode predict` - Predict context
- `neuracode impact` - Impact analysis
- `neuracode architecture` - Show architecture
- `neuracode hotspots` - Identify hotspots
- `neuracode understand` - Understand images
- `neuracode analyze` - Deep code analysis
- `neuracode export` - Export code graph
- `neuracode watch` - Watch for changes
- `neuracode compare` - Compare codebases
- `neuracode suggest` - Get AI suggestions
- `neuracode install` - Install for agents
- `neuracode uninstall` - Uninstall from agents
- `neuracode stats` - Show statistics
- `neuracode config` - Show configuration
- `neuracode serve` - Start MCP server
- `neuracode version` - Show version
